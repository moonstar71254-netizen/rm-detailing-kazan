РМ Детейлинг (RM-Detailing) — памятка по обновлению сайта

1. Где менять цены, услуги, адрес и график:
   Откройте файл src/data/siteConfig.js. Все тексты, список услуг,
   стоимость и ссылка на Telegram собраны там с подписями на русском.

2. Куда класть новые фотографии:
   Складывайте изображения в папку public/images/ (формат WebP или JPG).
   Имена файлов указываются в src/data/siteConfig.js в блоках hero и directions.

3. Как собрать сайт после правок:
   Выполните в папке проекта команды: npm install && npm run build

4. Какую папку загружать на хостинг:
   Загрузите содержимое готовой папки dist на любой статический хостинг
   (Timeweb, Reg.ru, Beget, Netlify или Vercel). Бэкенд не требуется.
